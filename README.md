## Description

**WatchList** is a web application that helps movie fans organize and manage the movies they want to watch and the movies they have already watched.

---

> ## Team Discussions
>
> > #### Branch Naming
> >

>
> > #### Code Standards

## Getting Started

Run the development server:

```bash
npm run lint
npm run build
npm run dev
```
